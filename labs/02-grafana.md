# Lab 2 - Dashboards (~15 min)

Open http://localhost:3000 (`admin` / `pizza`).

## 1. Tour (3 min)

- **Connections → Data sources**: `Prometheus` and `Loki` are already configured. Where? See `helm/kps-values.yaml` (`additionalDataSources`).
- **Dashboards → 🍕 Pizzeria**: shipped with the repo (`dashboards/pizzeria.json`, loaded by Grafana's sidecar from a labelled ConfigMap).
- Also browse the dashboards that came with kube-prometheus-stack, e.g. **Node Exporter / Nodes** and **Kubernetes / Networking / Namespace (Pods)**. (Per-container CPU/memory panels are empty on OrbStack, a cAdvisor limitation.)

Run `./scripts/chaos.sh fire` now and watch the dashboard react (refresh is 5s).

## 2. Build your own panel (7 min)

1. Open the Pizzeria dashboard → **Add → Visualization**
2. Datasource: Prometheus. Query:
   ```promql
   sum by (pizza) (rate(pizzeria_orders_total[1m])) * 60
   ```
3. Legend: `{{pizza}}`. Title: **Pizzas per minute**. Unit: *Misc → none*
4. Visualization: try **Bar gauge**, then **Time series** (stacked)
5. Add a **threshold**: red above 40
6. **Apply**

## 3. Use a variable (3 min)

*Dashboard settings → Variables → Add variable*:

- Type: **Query**, name: `pod`, datasource Prometheus
- Query: `label_values(pizzeria_orders_total, pod)`
- Enable *Multi-value* and *Include All*

Now edit your panel: `sum by (pizza) (rate(pizzeria_orders_total{pod=~"$pod"}[1m])) * 60`.
Pick a single pod from the dropdown at the top.

## 4. Dashboards as code (2 min)

*Dashboard settings → JSON Model* - that's the whole dashboard. Copy it. In this repo it's generated by `scripts/gen_dashboard.py`, and loaded by:

```bash
kubectl -n monitoring get cm pizzeria-dashboard --show-labels   # grafana_dashboard=1
```

**Challenge**: change a panel title in `scripts/gen_dashboard.py`, run it, then `./scripts/up.sh`. Did Grafana notice?

> Note: edits made in the UI are *not* persisted for provisioned dashboards. Export JSON and commit it. That is the point.
