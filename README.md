# 🍕 Kubernetes Monitoring Lab: Prometheus, Grafana & Loki

A hands-on workshop. Install a full monitoring stack on a local cluster, monitor a (very flammable) pizzeria, and play detective when the oven catches fire.

```
 pizzeria pods ──/metrics──► Prometheus ──┐
                                          ├──► Grafana ──► you 👀
 pizzeria pods ──stdout──► Alloy ► Loki ──┘
```

## Quick start

Requirements: a local Kubernetes cluster ([OrbStack](https://orbstack.dev), Docker Desktop, kind or minikube), `kubectl`, `helm`.

```bash
git clone https://github.com/professordiogodev/k8s-monitoring-lab
cd k8s-monitoring-lab
# default kube-context is "orbstack"; otherwise: export CTX=<your-context>
./scripts/up.sh      # ~3-5 min
./scripts/pf.sh      # Grafana http://localhost:3000 (admin/pizza), Prometheus :9090
```

Break stuff: `./scripts/chaos.sh random` · Fix it: `./scripts/chaos.sh off` · Clean: `./scripts/down.sh`

## What's in the box

```
app/pizzeria.py          the app (python stdlib only, ConfigMap-mounted: no image to build)
helm/                    values for kube-prometheus-stack, loki, alloy
manifests/               namespace, deployment, ServiceMonitor, PrometheusRule
dashboards/              the Pizzeria Grafana dashboard (generated by scripts/gen_dashboard.py)
scripts/                 up / down / pf / chaos
labs/                    step-by-step lab guides
```
